# 方法：实际采样状态与自条件历史的联合监督

## 1. 问题与实现目标

输入条件 c 是建筑二值图和单像素 TX 图（坐标取自同一 TX PNG），输出 y 是 256×256 灰度 RadioMap，按 PNG/255 表示。目标是在已有强普通自条件 FM 模型基础上进一步降低整图预测 RMSE，而不是靠新增平滑规则或改变评估口径取得表面改善。

训练与推理输入存在不一致：普通 FM 训练状态由 y 与噪声插值得到；真实推理状态来自模型过去的预测累积。自条件历史也受过去预测误差影响。这里将这一差异视为可针对的误差来源；实验收益支持这个监督方向，但不能据此证明它是所有误差的唯一来源。

## 2. 普通自条件基线究竟是什么

设噪声 epsilon ~ N(0,I)，时间 t ~ U[0,1)，标准直线路径为：

```text
x_t = (1-t) epsilon + t y
v_target = y - epsilon
y_hat = x_t + (1-t) v_theta(x_t, t, c, h)
```

模型是条件 U-Net，条件编码器在一次训练前向组/一次完整采样中共享。U-Net 接收当前状态、时间、条件特征、自条件参考和置信掩码；没有单独新增的几何预测网络。

普通训练采用 `lagged_history_three_pass`：

1. 从 N∈{10,25,50} 选择一个历史间隔 delta=1/N。
2. 在 max(t-2delta,0) 的插值状态上作一次无梯度预测，构造第一份终点参考。
3. 在 max(t-delta,0) 的插值状态上，带第一份参考作第二次无梯度预测，构造第二份参考。
4. 在 t 的插值状态上，带第二份参考作有梯度预测，并与 y-epsilon 对齐。10% 的样本将最终参考和置信掩码置零。

identity 参考的实际操作是 `h = y_hat * M_free`，置信掩码为 `M_free`。建筑像素不进入历史参考，但普通 FM 损失和正式整图 RMSE **仍包含建筑像素**；没有强行把输出建筑值置零。

两次历史预测不回传梯度；条件特征编码及最终预测按原实现训练。原 FM 损失：

```text
L_FM = sum_all_pixels (v_theta - (y-epsilon))^2 / number_of_all_pixels
```

## 3. 冻结父模型，获得实际输入分布

父模型 phi 固定为已选定强普通 EMA，其原验证 RMSE 为 0.0197166057。它不是在 RR 过程中同步更新的教师。

对固定 4000 张训练图，每张图使用缓存噪声种子 1003 和 1004 各采样一次。缓存噪声按场景/TX/种子确定，与验证噪声 1001/1002 分离。

只将条件输入 Euler25 采样器。每次 backbone 调用之前，记录：

```text
z_k : 父模型此时实际采样状态
h_k : 本次预测实际传入的自条件参考（上一轮预测终点的自由区值）
t_k = k/25, k in {7,15,21}
```

保存的是“本次预测之前的状态”和“本次预测传入的历史”，不是本次预测之后的状态或刚生成的新历史。代码通过 forward-pre-hook 从实际调用中捕获，避免错位。

轨迹生成不读取 GT；缓存状态和参考均为 FP32、detached。缓存固定为父模型分布，不是在线刷新或学生 on-policy 轨迹。

## 4. RR 监督到底改了什么

RR 在额外前向中使用 `(z_k,t_k,c,h_k)`：

```text
y_hat_RR = z_k + (1-t_k) v_theta(z_k,t_k,c,h_k)
L_RR = sum_all_pixels M_free * ((y_hat_RR-y)/(1-t_k))^2
       / number_of_all_pixels
L_total = L_FM + 1.0 * L_RR
```

RR 额外预测沿用普通训练同一份 null 掩码；被丢弃的参考和置信掩码同时置零。网络、建筑/TX 条件编码器和参数完全共用，不新增另一套预测头。

关键是正确的监督目标。任意实际状态 z 通常不等于 `(1-t)epsilon+t*y`，因此在该状态上不能继续盲用 `y-epsilon`。正确的终点指向速度为：

```text
v_endpoint = (y-z)/(1-t)
```

上面的终点误差除以 `(1-t)`，与 `v_theta-v_endpoint` 的平方误差等价。它修正实际输入上的终点预测，而不是强迫网络复刻父模型的错误终点。

原实现中的 `coarse_velocity_sum` 函数名来自早期基础工具，但原 RR 固定 **block_size=1**，这里不做低频块均值投影；每个自由像素都得到监督。归一化分母为整个有效 batch 的所有像素数，不是仅自由像素数。微批次各自的损失都用同一个全局分母，避免改变两项的相对权重。

普通 FM 损失及其时间采样没有被替换，RR 是附加监督。GT 只进入损失标签和原普通教师插值训练，不进入实际缓存的生成路径或 RR 额外预测输入路径。

## 5. 匹配训练与部署

普通/RR 两组共同初始化于同一个父模型 EMA；RR 适配阶段使用全新 AdamW 和 EMA，而非继承父模型优化器。有效 batch32、micro8、BF16；LR 从 200 步 warmup 升至 1e-5；EMA cap=.99、前 200 次复制。

两组样本顺序、基本噪声、时间、自条件历史间隔、null 掩码、缓存噪声选择及缓存时间槽保持一致。普通每微批次执行三次预测，RR 执行四次；移除了原研究辅助代码中的无效额外前向，但保留有效损失、梯度、Adam 和 EMA 更新。

推理仍为同一份 GT-free Euler25 采样器：从噪声开始，使用自身历史，连续做 25 次速度预测。无需访问缓存、训练标签或父模型，参数量仍为 **32,334,657**。RR 增加的是训练成本，不是新推理模块。

## 6. 当前可以如何作为论文核心表述

合理的主线是：“针对自条件流模型部署时的状态—历史联合分布，为实际采样输入构造终点指向监督，并保留原 FM 训练目标。”可以围绕分布不一致、联合输入监督和不改变部署结构展开。

已有证据是开发集上的匹配普通/RR 对照及当前最佳检查点，不应写成已完成独立测试、多父模型种子或所有近邻方法比较。与既有 trajectory supervision / self-conditioning 方法的区别及新颖性仍需正式相关工作核对；本仓库不提供未经核实的首创声明。
