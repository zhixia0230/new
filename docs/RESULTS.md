# 当前结果、统计口径和可支持的结论

## 1. 固定实验设置

源实验为 `strong_rr_v1`。共同起点为强普通自条件 EMA，RMSE=0.01971660571769083。新增训练使用 500 个场景各 8 个 TX，即 4000 张图，而不是父模型增强阶段使用的全 40000 张图。适配种子固定为 43；训练两组使用同父模型、相同抽样及随机流。

验证是复用的开发选择集 val_select：50 个场景，各 8 个 TX，每张图评估噪声 1001/1002。800 次预测不是 800 个统计独立的场景。指标由全部整图 SSE / 全部像素数开方得到，保留建筑像素、不裁剪预测、不转 dB。

## 2. 原 RR 学习曲线

| 新增步数 | 普通自条件 RMSE | RR RMSE | RR 相对普通的 RMSE 降幅 |
| --- | ---: | ---: | ---: |
| 1250 | 0.019686897566486866 | **0.019192126704927724** | **2.5131987399%** |
| 2500 | 0.019628918850206366 | 0.019245022131934984 | 1.9557710804% |
| 3750 | 0.0195993965682259 | 0.019283819748777763 | 1.6101353853% |
| 5000 | 0.01959245702883882 | 0.01930882071165698 | 1.4476812008% |

选用原 RR1250 作为当前主模型。1250 是这些已验证节点中的最佳，不代表已穷尽附近所有步数，也不是预先锁定后在独立 test 上选出的全局最优。

1250 步：RR 相对同节点普通模型的相对 RMSE 降幅 95% 场景 bootstrap 区间为 [2.1741510909%, 2.8559109218%]；49/50 场景改善，两组验证噪声均改善。相对冻结父模型 RMSE 降低 2.6600877467%。

5000 步同预算终点：RR 相对普通降低 1.4476812008%，95% 区间 [1.0449545935%, 1.8221266113%]；42/50 场景改善，两组噪声均改善。因此不应只公开最佳节点而隐去原方法后续变化。

这些区间来自原实验报告的 2000 次场景 bootstrap；它们不消除反复使用开发集调试、选择检查点造成的选择偏差，也不能代替独立随机种子实验。

## 3. 为何不把后期继续训练当作必然提升

原 RR 在 1250 步以后验证 RMSE 回升，说明在当前小训练池、固定父模型缓存和损失权重下，继续降低训练损失不必然改善泛化。现有分析支持“适配训练收益与后期泛化回退并存”，而不是证明所有 RR 方向失败，或证明单纯降低 LR/辅助权重一定有效。

本仓库不加入后续分叉实验或新的超参数方案；也不删除、覆盖本地历史。主方法、主检查点和未来独立验证应明确区分。

## 4. 证据如何核验

- `evidence/results.json`：原实验四个节点的指标与配对比较，均标明开发集及未评估 test。
- `evidence/per_sample/`：父模型、普通/RR1250、普通/RR5000 的逐图标识、SSE 和像素数，可重新汇总整图 RMSE 和进行场景配对分析，不含 RadioMap 图像。
- `evidence/source_manifest.json`：原实现、源报告、源 CSV 的 SHA256，父模型及最佳 RR 文件标识，发布迁移说明。
- `evidence/release_verification.json`：本次发布代码测试和原 RR1250 检查点重新验证的结果。

发布包中的源码已整理为可移植入口，故发布后的源码哈希和原研究树不同。不能把不同哈希说成原研究代码未经整理的原样归档；方法主体、模型、随机流不变，并单独核验。

## 5. 论文中可以和不可以写什么

可以写：在既有强普通父模型上，实际状态与历史的联合监督在本开发协议中有稳定的同节点收益；当前 RR1250 最佳，推理网络与 Euler25 NFE 不变。

不能据此写：已在独立 test 上证明；多模型种子稳定；全数据训练已经确认；与所有近邻方法比较后具有首创性或 SOTA；训练计算零成本；1250 步是任何训练条件下的最优停止点。

正式论文仍需将当前开发结论与锁定方案后的最终报告区分。这里保留这一界限，但不自动启动额外实验。
